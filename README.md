# CoeurMusiquesMetisses — Atelier numérique

Découvrir le numérique autrement

Que se passe-t-il vraiment quand nous utilisons un ordinateur, un téléphone ou une application ?

Cet atelier propose de le découvrir simplement, en utilisant la programmation et la musique comme support.

Pas besoin d'être informaticien : nous allons donner quelques instructions à l'ordinateur et observer ce qu'il fait. En faisant varier quelques commandes, nous verrons comment il « comprend » nos instructions et comment une suite de petites instructions peut produire un résultat.

L'objectif n'est pas d'apprendre à programmer, mais de mieux comprendre ce qui se cache derrière le numérique.

Et pour terminer, un petit débat convivial :
le numérique doit-il prendre toujours plus de place dans notre vie, ou pouvons-nous choisir la place que nous voulons lui donner ?

Un atelier ludique, accessible et sans prérequis.

## Installation

- Windows : double-cliquer sur `installation/INSTALLER_WINDOWS.bat`
- macOS/Linux : `bash installation/INSTALLER_MAC_LINUX.sh`
- Android : lire `installation/ANDROID.txt`

Après installation, lancer `atelier/test_installation.py`, puis les deux exercices.

Le module `atelier/georges.py` fournit une interface très simple aux participants.
