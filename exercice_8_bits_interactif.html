Exercice — Une lettre en 8 bits

Une lampe allumée = 1 et une lampe éteinte = 0.

Un ordinateur utilise des suites de 0 et de 1 pour représenter les informations.

1. Recherchez le code ASCII de « o » minuscule

Le code ASCII de o est :

01101111

Soit 111 en base 10 et 0x6F en hexadécimal.

2. Représentez ce code avec 8 torches

Cliquez sur chaque torche pour l'allumer ou l'éteindre.

Code : 00000000
Décimal : 0
Hexadécimal : 0x00
Lettre ASCII : ?

3. Que remarquez-vous ?

Avec 8 bits, on peut représenter 256 combinaisons différentes, de 00000000 à 11111111.

Une combinaison de 8 états peut représenter un caractère, comme la lettre « o ».

Question pour la discussion

Comment l'ordinateur peut-il savoir qu'une suite de 8 états électriques représente la lettre « o » ?
